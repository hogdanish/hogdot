# Translation-defining inputs of tint_convert_cli, hashed into its --pipeline-id.
# The editor's shader baker refuses to bake WGSL when the CLI's id differs from
# the one the editor was built with, so a stale binary degrades loudly to
# SPIR-V-only baking instead of shipping mismatched WGSL (RL-009's failure shape).
#
# Rules (RL-028: name every input):
# - Paths are repo-relative, hashed in listed order; lines starting with # are skipped.
# - Adding a Tint patch, or any file that changes what the translation pipeline
#   emits, means adding its path here in the same change.
# - A vendored Tint/SPIRV-Tools bump must be accompanied by a patches/ change or
#   a new line here; the vendored trees themselves are deliberately not hashed.
drivers/webgpu/spirv_preprocess.h
drivers/webgpu/spirv_preprocess.cpp
# The driver itself defines translation too: it owns the pass ORDER, the
# conditional freeze behind the runtime-overrides flag, and the WGSL rewrites
# (_apply_common_wgsl_passes, _rewrite_depth_texture_samples) that run after Tint
# and change the emitted text. Without it listed, a runtime-vs-bake divergence
# introduced here is invisible to the stale-CLI guard — which is the one check
# standing between a mismatched WGSL blob and a silent wrong render.
# ⚠ The cost is real and deliberate: every edit to this file now moves the
# pipeline id, so tint_convert_cli must be rebuilt (3 s) and the project
# re-exported before any bake-dependent number is quoted.
